# Web client

The running web client lives in the project root `src/` (React, Vite, Tailwind). This folder is reserved for a
standalone Next.js client if you later split the front end out of the root app.

Pages (in `src/pages`): Home, Explore, Watch, Studio (overview, videos, upload, earnings, settings), Wallet,
Library and Profile. The paid player is in `src/components/player`.
